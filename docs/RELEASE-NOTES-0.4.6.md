# DiPlay v0.4.6 — 方向盘通话键与 Siri 接管、通话麦克风修复、导航独立音源

广汽 GS5 专用版本。CarPlay 下方向盘的接听、挂断、语音键都交给 iPhone；修复通话和 Siri 时对方听不到声音的问题；导航播报改走车机的导航音源。

## 主要变化

### 方向盘按键
- 接听键接听来电，挂断键挂断或拒接，语音键短按、长按都唤起 Siri
- 需要打开「设置 → 高级 → 车辆 → CarPlay 通话按键（实验性）」，或 CarPlay 画面快捷菜单里的同名开关；默认关闭
- 按原厂 CarLife 的方式向系统接管按键，CarPlay 断开后交还给车机
- 每次按键的处理结果都写进诊断日志，方便排查

### 麦克风
- 修复 CarPlay 通话、Siri 和使用麦克风的 App 都录不到声音的问题。原因是原车语音助手的唤醒词一直占着麦克风，而这台车机同一时间只允许一路录音
- 使用麦克风期间暂停原车语音助手和唤醒词，用完恢复
- 录音没有真正开始时会自动重试，并写入诊断日志

### 导航声音
- 导航播报改走通知流，不再和音乐共用媒体流
- 播报期间向车机申请 CarPlay 专用的导航音源（与原厂 CarLife 的做法相同）：导航按导航音量播放，音乐压低但不暂停
- 注意：只有导航 App 把播报放在独立通道时才生效。Apple 地图是独立通道；高德地图目前把播报混进音乐里一起发送，车机这边无法分开，音量仍跟随媒体

### 无线连接
- 用 Wi-Fi 直连连接 iPhone 时，如果车机还连着别的 Wi-Fi，会弹出 5 秒倒数提示，到时断开车机自己的 Wi-Fi 连接，减少对 2.4 GHz 连接的干扰
- 提示有「保持 Wi-Fi」和「立即断开」两个按钮；Wi-Fi 本身不会关闭，CarPlay 结束后自动重连
- 会话期间关闭 Wi-Fi 直连接口的省电模式

### 其他
- 推送到 dev 分支时自动构建平台签名车机包

## 已知情况

- 方向盘按键接管在无线连接下实测正常，有线连接走同一套代码，尚未实测
- 导航独立音量需要导航 App 支持，见上文「导航声音」
