# DiPlay v0.5.2 — 首次启动不再卡、收音机下打电话、仪表转向提示

广汽 GS5 专用版本。在 0.5.0 的基础上修复首次启动卡顿、有线和无线的几个连接问题，并把 CarPlay 的转向提示送到原车仪表。

## 主要变化

### 启动
- 装完第一次打开不再卡十几秒、弹「无响应」：打包时裁掉没用到的库代码，首次启动要优化的代码从约 13 MB 降到约 1 MB，实车约 2 秒完成

### 通话和 Siri
- 收音机、蓝牙音乐播放时打 CarPlay 电话，车载喇叭有声音，和 Siri 一样申请音源，通话结束放开

### 有线连接
- 有线网络选 TUN 但连不上时，下一次重连自动改用 lwIP，并提示一次；不改设置，重启 DiPlay 或重新选择后恢复 TUN

### 无线连接
- 车机自己的 Wi-Fi 连着别的热点时，改为停用这个网络，不再反复断开又被系统连回去
- 选择「保持」或「暂停」后，自动重连沿用这次的选择，不再重复询问；手动断开或退出 DiPlay 时恢复车机 Wi-Fi，60 秒内没有新的无线连接接手也会恢复
- 提示不用系统的小对话框，改成车机大小的面板和大按钮

### 仪表
- 连接中途打开仪表地图或 DiPlay 自己重连后，仪表不再停在「导航系统未启动」，不用彻底断开重连
- 仪表占位按状态显示「等待 CarPlay 连接」或「等待 CarPlay 地图」
- 新增「仪表转向提示」（实验性，默认开，设置 → 仪表地图）：CarPlay 导航时把下一个路口的转向、距离、路名和剩余里程、时间送到原车仪表，显示在原车导航用的位置，路线结束时清掉。iPhone 不提供限速，所以不显示限速

## 上车情况
实测通过：首次启动（约 2 秒，没有无响应）、无线自动连接、Siri、无线时车机 Wi-Fi 的大按钮提示和「保持」选择。
还没实测：收音机下打 CarPlay 电话、TUN 自动改用 lwIP、Wi-Fi 选择在自动重连时沿用和之后的恢复、连接中途切仪表模式、仪表转向提示。
