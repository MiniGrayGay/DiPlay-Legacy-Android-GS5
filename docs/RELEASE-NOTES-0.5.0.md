# DiPlay v0.5.0 — 有线通话麦克风、常开麦克风、收音机下的 Siri、音量键接管

广汽 GS5 专用版本。在 0.4.6 的基础上修复了通话、Siri 和有线连接的一批问题，并加入音量键接管。

## 主要变化

### 麦克风、通话和 Siri
- 修复有线 CarPlay 打电话、用 Siri 时对方听不到声音
- CarPlay 连着时常开麦克风（默认开，设置 → 高级 → 高级媒体）：通话和 Siri 不用再等麦克风。原车语音占着不放时，先请它让出，约 1.5 秒仍拿不到就结束正在录音的程序。打开期间原车语音助手不能用
- 修复通话和 Siri 开头偶尔断 1 秒：车机的音频驱动在喇叭从休眠启动时，会重置以「通话」方式打开的录音，改用「语音识别」方式
- 收音机、蓝牙音乐时 Siri 有声音，说完恢复原来的音源；Siri 打断的音乐恢复时不再顶掉收音机
- 通话播放的延迟减小
- 修复倒车后麦克风录到静音、通话中断线后原车语音不恢复

### 有线连接
- 有线用久了新的播报和通话没声音的问题已修
- 有线会话后原地重连，不用再拔插
- 新增「有线网络」选择：TUN（内核态，默认）或 lwIP（用户态）。TUN 走系统 VPN，不需要 root

### 音量键
- 新增「音量键由 DiPlay 接管」，默认开：按键显示 DiPlay 的音量条，并按当前声音调媒体或导航音量。更新后第一次要重启车机

### 导航声音
- 播报时音乐按 dB 压低，播完立即恢复；播报等车机切到导航模式后再放，开头不再偏小

### 其他
- 「传祺」按钮的默认图标换成传祺标，品牌图标里加「传祺」
- 三指菜单没连接时也能打开，只保留四项常用开关
- 「设置 → 诊断」新增「车机自检」：约 2 分钟，没连和连上 CarPlay 各跑一次
- 只保留简体中文和英语，默认简体中文

## 默认值的变化
按实车用的设置，这几项改为默认开：有线网络 TUN、USB 直连模式（只在系统认不出 iPhone 时才用到）、音量键由 DiPlay 接管、CarPlay 通话按键、CarPlay 期间关闭蓝牙自动连接。高效硬件图层渲染（默认开）、音乐缓冲 300 毫秒不变。手动改过的设置不受影响。

## 上车情况
实测通过：有线通话和 Siri、收音机下的 Siri、音量键接管、常开麦克风、有线 TUN（重启后自己连上）。
还没实测：收音机下打 CarPlay 电话、通话延迟的改善、Siri 后音乐不顶掉收音机、倒车后的麦克风、开关「音量键由 DiPlay 接管」关闭后立即交还车机。
